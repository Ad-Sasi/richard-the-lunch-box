# The Lunch Box — prototype

Prototype du site pour "The Lunch Box" (cuisine indienne de Richard Balaraj, Nantes), à montrer avant l'achat d'un nom de domaine.

- [`index.html`](index.html) — version C, motif indien (piste retenue par défaut)
- [`v1.html`](v1.html) — version A, fidèle au flyer
- [`v2.html`](v2.html) — version B, illustration éditoriale
- [`variantes.html`](variantes.html) — page de comparaison des 3 pistes

Aucun build : chaque page charge React + Babel en CDN et transforme le `.jsx` correspondant directement dans le navigateur. Pour changer une page, éditer le fichier `.jsx` associé.

Hébergé gratuitement via GitHub Pages, sans nom de domaine ni serveur.
